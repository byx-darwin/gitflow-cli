# Design: Rename gitflow-cli → gf

**Date:** 2026-08-04
**Issue:** #124
**Status:** Approved
**Approach:** A — Single atomic rename

## Background

Current CLI name `gitflow-cli` is too long for daily use. Since the project has no external users yet, a clean rename to the shorter `gf` is feasible with no backward compatibility concerns.

## Goals

Rename all `gitflow-cli*` packages and binaries to `gf*`:

| Original | New |
|----------|-----|
| `gitflow-cli` | `gf` |
| `gitflow-cli-core` | `gf-core` |
| `gitflow-cli-github` | `gf-github` |
| `gitflow-cli-gitlab` | `gf-gitlab` |
| `gitflow-cli-gitcode` | `gf-gitcode` |

## Non-Goals

- **GitHub repository rename** — `byx-darwin/gitflow-cli` stays unchanged. All repo URLs remain as-is.
- **crates.io old package yanking** — Old `gitflow-cli*` packages remain on crates.io with an archived/deprecated notice. No yank operations.
- **Directory structure rename** — `crates/core`, `crates/github`, `apps/cli` etc. keep their directory names. Only Cargo `name` fields and all references change.
- **Skill directory rename** — `.claude/skills/gf-workflow/` etc. keep their names (skill identifiers are decoupled from CLI command names).

## crates.io Strategy

- Publish `gf`, `gf-core`, `gf-github`, `gf-gitlab`, `gf-gitcode` as **new packages** on crates.io.
- Old `gitflow-cli*` packages **remain published** as-is. Add an archived/deprecated notice to their README.
- No yanking of old versions.

## Change Scope

### Part 1: Cargo / Workspace Manifests (7 files)

**Root `Cargo.toml`:**
- `[workspace.dependencies]`: rename all 5 crate references from `gitflow-cli*` → `gf*`

**`apps/cli/Cargo.toml`:**
- `[package] name` → `"gf"`
- `[[bin]] name` → `"gf"`
- All dependency references: `gitflow-cli-core` → `gf-core`, etc.
- `description`, `keywords`, `documentation` URL updates

**`crates/core/Cargo.toml`:**
- `name` → `"gf-core"`
- `description`, `keywords`, `documentation` updates

**`crates/github/Cargo.toml`, `crates/gitlab/Cargo.toml`, `crates/gitcode/Cargo.toml`:**
- `name` → `"gf-{platform}"`
- Dependency `gitflow-cli-core` → `gf-core`
- `description`, `keywords`, `documentation` updates

**`Cargo.lock`:** auto-regenerated by `cargo build`.

### Part 2: Rust Source Code (~33 files)

**Global text replacement across all `.rs` files:**

| Pattern | Replacement |
|---------|-------------|
| `gitflow_cli_core` | `gf_core` |
| `gitflow_cli_github` | `gf_github` |
| `gitflow_cli_gitlab` | `gf_gitlab` |
| `gitflow_cli_gitcode` | `gf_gitcode` |

**Specific locations:**

| File | Change |
|------|--------|
| `apps/cli/src/main.rs` | `#[command(name = "gitflow-cli")]` → `#[command(name = "gf")]`; `about` text; module doc comments |
| `apps/cli/src/commands/completions.rs` | Completion filenames: `"gitflow-cli.bash"` → `"gf.bash"`, `"_gitflow-cli"` → `"_gf"`, `"gitflow-cli.fish"` → `"gf.fish"`; test assertion strings |
| `apps/cli/build.rs` | Doc comment `//! Build script for gitflow-cli` → `//! Build script for gf` |
| All `lib.rs` files | Doc comments referencing `gitflow_cli_*` module paths |
| All doc tests | `/// use gitflow_cli_*::...` → `/// use gf_*::...` |
| E2E test crates | `crates/e2e-core/src/tty.rs`, `crates/e2e-core/tests/harness.rs` — hardcoded binary name references |

### Part 3: Documentation (~141 markdown files)

| File / Directory | Change |
|------------------|--------|
| `README.md` | All `gitflow-cli` command examples → `gf` |
| `CHANGELOG.md` | Historical entries **preserve original names**. Add new entry under `[Unreleased]` documenting the breaking rename. |
| `CONTRIBUTING.md` | Command references |
| `CLAUDE.md` | All command references and skill documentation commands |
| `docs/*.md` | All command examples and references (~20+ files) |
| `specs/*.md` | Command references in design documents |
| `crates/*/README.md` | Package names and descriptions in each crate README |

**CHANGELOG.md strategy:**

```markdown
## [Unreleased]
### ⚠ BREAKING CHANGES
- rename: `gitflow-cli` → `gf`, all crate names renamed accordingly

## [0.9.0] - <original date>
(Historical entries unchanged — still reference gitflow-cli)
```

**Preserved references (not changed):**
- `cliff.toml`: `$REPO` URL stays `https://github.com/byx-darwin/gitflow-cli` (repo name unchanged)
- GitHub repo URLs in documentation (repo name unchanged)

## Validation / Exit Criteria

| # | Check | Command |
|---|-------|---------|
| 1 | Build passes | `cargo build --all-targets --all-features` |
| 2 | All tests pass | `cargo test --all-targets --all-features` |
| 3 | Binary name correct | `./target/debug/gf --version` outputs `gf x.y.z` |
| 4 | Help output correct | `./target/debug/gf --help` shows `gf CLI tool` |
| 5 | No stale references | `grep -r "gitflow-cli" --include="*.rs" --include="*.toml" .` only matches repo URLs and CHANGELOG history |
| 6 | Cargo package names | `cargo metadata --format-version 1` shows all packages as `gf*` |
| 7 | Shell completions | `./target/debug/gf completions bash` generates output referencing `gf` |

## Execution Order

1. Cargo manifests (workspace root + all crates)
2. Rust source code (imports, command names, doc comments, tests)
3. Test fixtures (trycmd)
4. Shell completion code + tests
5. Documentation (README, CHANGELOG, docs/, specs/, CLAUDE.md)
6. Skills (all SKILL.md files + schema + references)
7. CI/CD workflows
8. Homebrew formula (rename file + update content)
9. Makefile
10. Local configuration (optional)
11. Run full validation (build + test + grep check)

## Risks and Mitigations

| Risk | Mitigation |
|------|------------|
| Mechanical replacement misses a reference | Grep validation step (check #5) after all changes |
| Cargo.lock out of sync | Auto-resolved by `cargo build` |
| Shell completion scripts break | Existing tests in `completions.rs` cover filename generation |
| CI/CD fails on renamed binary | All workflow files updated in same PR |
| Homebrew formula breaks | Formula file renamed + content updated in same PR; release workflow references updated |
| crates.io name collision | Verify `gf` / `gf-core` / `gf-*` names are available on crates.io before publish |
