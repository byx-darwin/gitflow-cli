# v1.0.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release v1.0.0 across crates.io, Homebrew, and GitHub with complete documentation and support policy.

**Architecture:** Three-phase release: (1) Fix #111 bug + verify, (2) Prepare documentation (SUPPORT.md, website, compatibility matrix), (3) Execute dogfooding + release + verify deployment.

**Tech Stack:** Rust 2024, cargo-release, git-cliff, GitHub Actions, Astro (website), Homebrew formula.

## Global Constraints

- Rust edition: 2024, toolchain pinned in `rust-toolchain.toml`
- Version: 0.9.0 → 1.0.0 (workspace + all crates)
- crates.io packages: gf-core, gf-github, gf-gitlab, gf-gitcode, gf (publish in dependency order)
- Homebrew formula: `HomebrewFormula/gf.rb` (auto-updated by CI)
- GitHub Pages: `website/` directory, deployed via `website.yml` workflow
- Dogfooding: GitHub + GitCode only (GitLab skipped, environment unavailable)
- Release script: `scripts/release.sh` (interactive, with dry-run)
- Must pass: `make test`, `make clippy`, clean working directory before release
