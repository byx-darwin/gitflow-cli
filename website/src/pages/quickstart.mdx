# 5 分钟快速上手

## 0. 前置条件

跑 `/gf-workflow` 前需准备好 Agent 运行环境与技能来源：

- **Claude Code** — Agent 运行环境。推荐[原生安装](https://code.claude.com/docs/en/setup)（`curl -fsSL https://claude.ai/install.sh | bash`，自带二进制、无需 Node.js）；若用 npm 安装则需 Node.js 22+。
- **技能来源** — `superpowers` 或 `mattpocock-skills` 之一，`/gf-workflow` 的编排引擎来自其中之一。**未安装任一来源时 `gf skills install` 会硬阻断并中止。**
- **Node.js ≥ 22.20.0** — 仅安装 `mattpocock-skills` 来源时需要：`claude plugins install mattpocock-skills` 与 `npx skills@latest` 都会拉起 `mattpocock/skills` 工具链（其 `skills` CLI 要求 Node ≥ 22.20.0）。`superpowers` 为纯 skills，无需 Node.js。先运行 `node --version` 确认。

安装技能来源（任选其一）：

```bash
claude plugins install superpowers        # 全自动流水线
claude plugins install mattpocock-skills  # 人工驾驶流水线（需 Node.js ≥ 22.20.0）
# 或
npx skills@latest add mattpocock/skills   # 需 Node.js ≥ 22.20.0
```

## 1. 安装 gf

```bash
brew tap byx-darwin/tap && brew install gf
# 或
cargo install gitflow-cli
```

## 2. 安装 Skills

```bash
gf skills install        # 项目级（推荐，跟随仓库）
gf skills install -g     # 全局（所有项目可用）
```

不指定 `--agent` 时自动检测目标 Agent 平台（Claude Code / Codex / OpenCode / Gemini / Copilot）。

> 需先完成[第 0 步](#0-前置条件)安装技能来源，否则 `gf skills install` 会因「未检测到任何技能来源」而中止。

## 3. 验证

```bash
gf skills list           # 应看到 26 个 gf-* skills
gf --version
```

## 4. 开始开发

在支持的 Agent 平台中输入：

```
/gf-workflow 我要做 X
```

即可进入四阶段编排：**需求澄清 → 计划制定 → 执行 → 交付后检查**。

> 平台会基于 git remote 自动检测（GitHub / GitLab / GitCode），也可用 `--platform` 手动指定。
