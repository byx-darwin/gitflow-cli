# gf 命令索引

> 当前顶层命令与子命令的机器可读索引。精确参数、默认值与平台差异以已安装版本的 `gf <command> <subcommand> --help` 为准。

## 全局选项

- `--platform github|gitlab|gitcode`：覆盖基于 git remote 的平台检测。
- `--output json|text|toon|auto`：选择输出格式，默认 `auto`。
- `--verbose`：输出详细诊断。
- `--help`：显示帮助。
- `--version`：显示版本。

## gf decide — 类型化决策

子命令：`noul`、`choice`、`score`、`batch`、`eval`、`calibrate`、`compare`。

## gf regression — 回归语义评估

子命令：`semantic-eval`。

## gf issue — Issue 管理

子命令：`search`、`create`、`edit`、`list`、`view`、`precheck`、`close`、`reopen`、`comment`、`comments`、`add-label`、`remove-label`。

## gf pr — Pull Request 管理

子命令：`search`、`create`、`list`、`view`、`precheck`、`close`、`reopen`、`comment`、`merge`、`checkout`、`ready`、`wip`、`sync`、`diff`、`patch`、`cleanup`。

## gf release — Release 管理

子命令：`create`、`list`、`view`、`edit`、`upload`、`download`、`delete`。

## gf review — 代码审查

子命令：`comment`、`approve`、`request-changes`、`submit`。

## gf auth — 认证管理

子命令：`login`、`logout`、`status`、`token`。

## gf label — 标签管理

子命令：`create`、`list`、`edit`、`delete`。

## gf milestone — 里程碑管理

子命令：`create`、`list`、`edit`、`close`、`reopen`。

## gf commit — Commit 管理

子命令：`view`、`diff`、`patch`、`comment`。

## gf pipeline — CI/CD 流水线

子命令：`analyze-failures`、`status`、`logs`、`jobs`、`report`。

## gf workflow — Workflow 合同管理

子命令：`progress`、`context`、`semantic-check`、`recommend`、`create`、`list`、`status`、`archive`、`cleanup`。

## gf doctor — 环境诊断

诊断底层 CLI、Agent、Skills 与配置状态。

## gf skills — Skills 管理

子命令：`suggest`、`install`、`list`、`uninstall`、`update`。

`install`、`list`、`uninstall` 和 `update` 默认使用 Claude Code。通过 `--agent claude|codex|open-code|gemini|copilot|qoder|pi` 显式选择其他 Agent；通过 `--path` 指定自定义目录。

## gf update — 自更新

将 gf 二进制更新到最新 GitHub Release。
